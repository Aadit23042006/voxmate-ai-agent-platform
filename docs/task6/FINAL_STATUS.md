## External actions required by the submission platform

A ZIP file cannot publish to a GitHub account, create a hosting deployment, upload a video, or publish a LinkedIn post. Before submitting the company form, the repository owner must:

1. Push the extracted project to GitHub.
2. Add `GEMINI_API_KEY` as a hosting secret/environment variable.
3. Deploy the included Docker/Render configuration and verify `/` and `/api/capstone/health`.
4. Record the demo using `DEMO_SCRIPT.md` and upload it where required.
5. Publish `LINKEDIN_POST.md` and keep the final public post URL.
6. Submit the GitHub URL, live website URL, and LinkedIn URL in the company portal.

The source package itself contains the implementation and documentation for all items in the Task 6 brief.
